# Avatar

A person, at a glance. Initials by default, a photograph when the content database has one.

## Rules

- Initials are first and last, uppercase, on `brand-100`. Never a random colour per person: colour would imply a meaning the product does not have.
- `sm` inside a table row, `md` beside a name, `lg` on a record header or a proof page.
- The name is always available to assistive technology through `aria-label`, and an avatar is never the only place a name appears in a row.
- Photographs are real people from the content database who agreed to appear. No stock, no generated faces.
- Never stack more than three avatars in a group; show "+4" as text beside them.

## The consumer provides

The name and, if it exists, the image URL.
