# EmptyState

What a person sees before there is anything to see. Treat it as the first screen of the product, because for a new FFN operator it is.

## Rules

- The title states the fact plainly and without apology: "No leads in this view yet". Never "Oops" and never an exclamation mark.
- The body says where the records come from, so the operator learns the model from the empty screen.
- Give it one primary action and at most one secondary. If there is genuinely nothing to do, say what will cause records to appear instead.
- Distinguish the three empties and write each differently: nothing created yet, nothing matching this filter, nothing left to do. The third is good news and should read like it.
- The mark is a `brand-050` tile with a Lucide icon. No illustration, no mascot.

## The consumer provides

The copy, the actions, and which of the three empty cases it is.
