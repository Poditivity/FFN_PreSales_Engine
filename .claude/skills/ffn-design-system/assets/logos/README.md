# Logos

The four FFN marks, copied from the FFN Brand Book. These are the only approved forms. Do not recolour them, do not redraw them, do not set the wordmark in a different typeface, and do not place the mark inside a circle unless you are using `ffn-lockup-on-light.png`, which already carries that treatment.

The mark reads as two overlapping `F` forms, cut from hard diagonals with square terminals. The brand book states the construction as founder plus founder plus networking. That geometry is where this system's tight radii come from.

| File | Use it |
| --- | --- |
| `ffn-lockup-on-light.png` | The full lockup, mark and wordmark, on any light ground. Application login, the intake form header, PDF and email headers. Minimum width 180px. |
| `ffn-mark-blue.png` | The mark alone in FFN blue on a light ground. The app top bar, the collapsed sidebar, the favicon source. Minimum 24px. |
| `ffn-mark-on-blue.png` | The mark reversed out of a `brand-solid` ground. Use when the mark sits inside a filled blue block, never on a light ground. |
| `ffn-mark-on-black.png` | The mark reversed out of black. Use on `surface-inverse` and in the dark theme's top bar. |

These are raster PNGs at the size the brand book supplied. For print, for anything above 512px, or for a favicon set, get vector source from FFN rather than upscaling these.

Clear space on every side is at least the height of the mark's counter, which is roughly a fifth of the mark's height. Nothing sits inside that space.

There is no FFN icon set. Product icons come from Lucide, which is a substitution this system made and which the brand book does not cover.
